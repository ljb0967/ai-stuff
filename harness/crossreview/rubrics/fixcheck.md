# 검토 기준: 수정 반영 확인 (fixcheck)

앞선 교차 검토에서 나온 지적과, 제작자가 "✅ 반영"이라고 표시한 반영표(아래 첫 파일)가 있습니다.
그 뒤에 수정된 교안의 해당 페이지 이미지와 추출 텍스트가 있습니다.

다음을 엄격하게 확인하세요.

1. 반영표에서 ✅로 표시된 항목이 **실제로 페이지에 반영되었는가?** 반영되지 않았거나 일부만 반영된 항목을 찾아라.
2. 수정 때문에 **새로 생긴 문제**(사실 오류, 문장 어색함, 앞뒤 단원과의 모순, 정답·해설 불일치, 레이아웃 깨짐)가 있는가?
3. 새로 넣은 연락처·법률·통계 표현이 2026년 11월 기준으로 틀릴 위험이 있는가?

findings 의 issue 에는 반영표 번호(C1, M3, m7 등)를 앞에 적고, 새 문제는 "NEW"라고 적으세요.
반영이 모두 확인되고 새 문제가 minor뿐이면 verdict 를 pass 로 하세요.
