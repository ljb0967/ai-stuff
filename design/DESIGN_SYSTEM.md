> 이 문서에 없는 색·글꼴·컴포넌트는 쓰지 않는다. 새 모양이 꼭 필요하면 `textbook/templates/blocks.html.j2`에 컴포넌트로 추가하고 이 문서를 먼저 고친다.

## 4. 페이지 유형 (수학 문제집 대응)

| 유형(`type`) | 머리 표시 | 필수 요소 |
|---|---|---|
| `opener` 단원 도입 | UNIT 번호 + 제목 | 학습 목표 3개, 왜 배우나요?, 생각 열기, 핵심 용어, 단원 흐름 |
| `concept` 개념 익히기 | `02-1` 남색 번호 상자 + 명조 제목 | 줄글 ≤ 800자, **시각 자료 1개 이상**, 개념 상자 권장, 곁단 메모 |
| `example` 예제 | 주황 `예제` 라벨 | 예제(문제→풀이→답), 유제 |
| `practice` 따라 해 보기 | 주황 `따라 해 보기` 라벨 | 단계(번호 원) + 입력 예시(prompt) + 화면 모식도 |
| `exercises` 확인 문제 | 남색 `확인 문제` 라벨 | 4~6문항, 난이도 ★1~3, 정답은 부록 |
| `summary` 단원 마무리 | 남색 `단원 마무리` 라벨 | 핵심 정리, 오해와 진실, 스스로 점검하기 |

## 5. 컴포넌트 목록 (이것만 쓴다)

| 분류 | 컴포넌트 | YAML 키 |
|---|---|---|
| 글 | 단락 · 도입 문장 · 소제목 · 목록 | `p` `lead` `h3` `list` `olist` |
| 상자 | 핵심 개념(남색 테두리+탭) · 주의(빨강) · TIP(주황) · 더 알아보기(남색) · 오해와 진실 | `concept` `warn` `tip` `info` `myth` |
| 곁단 | 용어 · TIP · 주의 · 알아 두기 | `note` (`kind: term/tip/warn/fact`) |
| 그림 | 막대그래프 · 낱말 조각 · 흐름도(가로/세로) · 계단 · 순환도 · 포함 관계 · 허브 · 대화 화면 · 채팅 화면 해설 · 에이전트 작업 화면 · 승인 창 · 타임라인 · 2×2 판단표 · 권한 사다리 · 비교 · 카드 · 하루 일과 · 가명 처리 전후 · 요청문 분해 | `figure` (`kind: bar/tokens/flow/stairs/cycle/nested/hub/chat/chatui/agentlog/approval/timeline/matrix/ladder/compare/cards/dayline/redact/decompose`) |

| 문제 | 예제 · 유제 · 확인 문제(객관식·OX·짝짓기·단답·서술·실습) | `example` `similar` `exercises` |

| 정리 | 핵심 정리 · 스스로 점검하기 | `summary` `checklist` |

## 6. 그림 규칙

- 화면 그림은 **특정 회사 로고·이름이 없는 일반화된 모식도**로 그린다(창 이름 "AI 대화", "에이전트 작업 화면").
- 모든 그림·표에는 **번호 + 캡션**(`그림 2-1`, `표 3-1`, `그래프 1-1`)을 단다. 캡션은 그림만 봐도 뜻이 통하게 쓴다.
- 가상의 수치는 캡션에 **"(설명을 위한 가상의 값)"** 을 반드시 쓴다. 실제 통계는 **출처와 시점**을 쓴다.
- 색만으로 뜻을 전하지 않는다. 신호등·강조에는 글자나 기호를 함께 쓴다.

## 7. 원고 작성 규칙 (하네스가 검사)

| 규칙 | 기준 | 검사 |

| 페이지 넘침 | 본문 영역 밖으로 나가면 안 됨 | `render.mjs` overflow (오류) |
