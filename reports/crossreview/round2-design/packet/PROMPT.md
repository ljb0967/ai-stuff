# 검토 기준: 디자인 시안 비교 (design)

첨부된 이미지는 같은 내용을 서로 다른 디자인으로 만든 A4 교안 시안들입니다(파일명에 시안 이름 A/B/C).
교안은 "고등학교 수학 문제집" 형식을 따르고, 독자는 AI 지식이 없는 중장년층·비전공 성인입니다.

각 시안을 아래 기준별로 1~5점 매기고, 가장 적합한 시안 하나를 추천하세요.

1. 중장년층 가독성(글자 크기·대비·행간)
2. 수학 문제집다운 느낌(개념 박스, 예제·풀이, 문항 번호 체계)
3. 정보 위계(제목→소제목→본문→보조 정보가 한눈에 구분되는가)
4. 도표·그림 수용력(본문과 시각 자료가 자연스럽게 배치되는가)
5. 흑백 인쇄 시 견고성
6. 90쪽 분량으로 확장했을 때의 일관성·유지 쉬움

findings 의 location 에 시안 이름을 쓰고, summary 에 추천 시안과 이유를 쓰세요.
점수표는 findings 와 별도로 summary 안에 "A: x/30, B: y/30, C: z/30" 형식으로 넣으세요.
출력 형식(JSON 하나만 출력):
{
  "overall_score": 0~100 정수,
  "verdict": "pass" | "revise" | "fail",
  "summary": "한두 문장 총평",
  "findings": [
    {"severity": "critical|major|minor",
     "category": "정확성|난이도|구성|안전·윤리|디자인|문체|기타",
     "location": "파일명/페이지/단원 등 위치",
     "issue": "무엇이 문제인가",
     "suggestion": "어떻게 고치면 되는가"}
  ]
}
