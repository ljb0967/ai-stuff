# 교안 기획서 — 『처음 배우는 AI 리터러시: 질문하기부터 에이전트에게 일 맡기기까지』

> 기획 단계 산출물 · 근거: `docs/research/01~04` · **1차 교차 검토 반영: `revision_round1.md` (이 문서보다 우선)**

## 1. 교안 개요

| 항목 | 내용 |
|---|---|
| 대상 | AI 지식이 전혀 없는 비전공 성인, 중장년층(40~60대 이상) |
| 최종 목표 | 학습 후 **에이전틱 AI를 골라 쓰고, 일을 맡기고, 권한을 관리하고, 결과를 검수**할 수 있다 |
| 형식 | 고등학교 수학 문제집 형식 (개념 → 예제 → 유제 → 확인 문제 → 정답 및 해설) |
| 판형 | **A4 (210 × 297 mm)**, 인쇄·PDF 겸용 |
| 분량 | 4부 12단원 + 앞부분 + 부록, 약 90~96쪽 (4부 = 12단원 중 5단원, 약 40%) |
| 학습 시간 | 단원당 60~90분 (강의 30분 + 실습 30~60분), 총 12~18시간 |
| 활용 | ① 강사용 수업 교재 ② 혼자 공부하는 워크북 |

## 2. 학습 목표 체계 (UNESCO 3수준 × OECD·EC 4영역)

| 부 | 수준 | 주요 영역 | 부 목표 |
|---|---|---|---|
| **1부 AI와 친해지기** | 이해 | Engaging | AI가 무엇이고 생성형 AI가 어떻게 답을 만드는지 쉬운 말로 설명한다 |
| **2부 AI와 대화하기** | 적용 | Creating | AI 서비스를 시작하고, 원하는 결과가 나오도록 요청하고 다듬는다 |
| **3부 AI를 믿을 수 있게 쓰기** | 적용·평가 | Engaging · Designing | AI의 답을 확인하고, 개인정보·사기·저작권 위험을 피한다 |
| **4부 AI에게 일 맡기기** | 창조 | **Managing** | 에이전트에게 일을 위임하고, 권한을 정하고, 감독·검수하는 루틴을 만든다 |

## 5. 페이지 밀도 규칙 (하네스가 자동 검사)

| 규칙 | 기준 | 이유 |
|---|---|---|
| 한 페이지 한 개념 | 개념 페이지의 소단원 제목 1개(최대 2개) | 인지부하 |
| 본문 글자 수 | 한 페이지 줄글 합계 **800자 이하**(공백 포함, 박스·표 제외) | 과밀 방지 |

## 7. 제작 원칙

1. **제품 중립**: 본문에는 특정 서비스 이름·로고를 쓰지 않는다. 화면 그림은 일반화된 모식도로 그린다.
2. **통계는 출처와 시점 표기**.
3. **나선형 반복**: "AI는 틀릴 수 있다 → 확인한다 → 사람이 최종 책임"을 2·6·9·12단원에서 반복한다.
4. **윤리 분산**: 단원마다 ⚠ 주의 박스 1개 이상.
5. **디자인 일관성**: 시안 3종 중 하나를 고른 뒤 `design/DESIGN_SYSTEM.md`의 규칙만 사용한다. 모든 페이지는 같은 템플릿·컴포넌트로 렌더링한다.
